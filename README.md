# retro-trace-research

Retrospective stage-attribution of laboratory workflow quality events
(delays and rework). A research codebase for attributing rule-labeled quality
events to individual workflow stages, with calibrated uncertainty handling.

The data package contains synthetic case records for method demonstration and reproducibility, generated by a seeded, deterministic generator. All records are fictionalized; no record corresponds to an actual patient, accession, or laboratory.

## What this repository contains

- **Event dictionary** (`src/retro_trace/a1/data/stage_map_v1_0.csv`):
  a pinned, versioned mapping of raw event codes to seven canonical workflow
  stages across three sites and three workflow versions. Integrity is
  enforced by a pinned SHA-256 recorded in `configs/qa_labels.yaml`
  (the pinned copy is byte-identical to the STAR-TAT stage map as of its
  v1.0 freeze, 2025-06-10); any modification raises an integrity error.
- **Research data generator** (`generate-synthetic`): deterministic
  generation of a 3,500-case package (seed 20250710) with planted delays
  (~12%), rework events (~8%), dual-stage deviations (~3%), and one
  site (SITE_C, all three workflow versions) marked not comparable.
- **Attribution engine** (`a1 attribute`): a six-step pipeline
  (dictionary unification, retrospective rule-based flagging, per-stage
  deviation against class baselines, subgroup association, ambiguity
  detection, cross-site comparability) producing per-case decisions of
  `LOCALIZED` or `ABSTAIN` with one of three reasons
  (`AMBIGUOUS_STAGES`, `INSUFFICIENT_BASELINE`, `NOT_COMPARABLE_SITE`).
- **Evaluation** (`a1 evaluate`): localization agreement, flag
  precision/recall, abstention-tier calibration, rejection rate, and a
  three-baseline comparison (naive longest-wait heuristic, fixed
  thresholds, per-stage statistical process control).
- **Ground-truth isolation**: the quality-event labels are staged under
  `data/_ground_truth/` in each run. Attribution never reads that directory;
  deleting it leaves every attribution output byte-identical (enforced by
  test).

## Quick start

```bash
uv venv venv --python 3.12
uv pip install --python venv/bin/python3 -e ".[dev]"

venv/bin/python3 -m retro_trace generate-synthetic --output synthetic_data/ --seed 20250710
venv/bin/python3 -m retro_trace validate --input synthetic_data/
venv/bin/python3 -m retro_trace a1 attribute --input synthetic_data/ --out outputs/runs/a1_attribution
venv/bin/python3 -m retro_trace a1 evaluate --run outputs/runs/a1_attribution/ --out outputs/runs/a1_evaluation
venv/bin/python3 -m retro_trace manifest inspect --run outputs/runs/a1_attribution

venv/bin/python3 -m pytest
```

## Interpretation

Every localized stage is a statistical association, not a causal claim
(association, not causation). A localized stage is a candidate focus area
for quality review, not proof that the stage caused the event. High
uncertainty means the localization confidence is low (at chance level by
design); such localizations are reported as low-confidence, not presented
as findings.

## Layout

- `configs/` — frozen configuration: quality-event labels, label rules,
  pinned dictionary hash.
- `schemas/` — column schemas for the four research tables.
- `src/retro_trace/` — common utilities and the `a1` research package.
- `tests/` — 40+ tests covering dictionary integrity, generator
  reproducibility, engine counterexamples, calibration, isolation, CLI,
  and repository red lines.
- `synthetic_data/` — the shipped, seed-reproducible research data package.
- `docs/` — method card, data dictionary, usage guide, frozen metrics.
- `research/decisions/` — numbered research decision records.
- `external/` — external validation protocol draft and status.
- `outputs/runs/` — run directories (manifest, results, logs, excluded
  rows, isolated ground truth).

## Reproducibility

Same seed, same inputs, same configuration produce the same data hash and
the same attribution result hash. The shipped data package is reproduced
byte-for-byte by `generate-synthetic --seed 20250710` (test-enforced).
