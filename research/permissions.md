# Permissions and access control (internal research)

- All data in this repository consists of synthetic case records for
  method demonstration and reproducibility, generated by a seeded,
  deterministic generator.
- Runs are classified `INTERNAL_RESEARCH`. External validation runs
  require the protocol in `external/EXTERNAL_VALIDATION_PROTOCOL_DRAFT.md`
  and use the other run status value.
- Quality-event labels (rule-labeled) are staged under
  `data/_ground_truth/` in each run directory. Access to those files is
  restricted to the
  evaluation step and the staging writer; attribution code never reads
  them (enforced by test).
- No personal data: case keys are synthetic identifiers, sites are role
  ids, and reviewers are role ids.
